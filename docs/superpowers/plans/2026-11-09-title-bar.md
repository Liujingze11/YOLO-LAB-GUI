# 标题栏合并 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline, following the project's single-agent convention.

**Goal:** 快捷键、居中项目名和窗口按钮合并为一行。
**Architecture:** 独立 WorkbenchTitleBar 管理窗口装饰与系统移动/缩放，在外层 QMainWindow.menuWidget 安装，复用现有快捷键入口及关闭路径。
**Tech Stack:** Python / PyQt5 5.15。
**Spec:** docs/superpowers/specs/2026-11-09-title-bar-design.md

## Global Constraints

- 单代理；在现有迁移工作区就地修改，不提交其他已有改动。
- 不改个人 software.yaml；关闭仍执行既有保存及后台任务保护。
- 所有工作页和首页使用同一标题栏。

## Review Focus

- 很长的中文项目名不得覆盖两侧按钮。
- 最大化和全屏时不允许边缘缩放。
- 最大化拖回普通窗口，以及最小尺寸约束。
- 子对话框和内部标注控件不受主窗口边缘事件处理影响。
- 关闭取消、深色按钮可读性、缩放比例变化。
