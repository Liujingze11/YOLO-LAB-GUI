# 回车创建和默认项目名 Implementation Plan

> 用户最新要求替代此前必填名称的行为：未命名使用默认名称，回车创建并进入。沿用单代理本地执行，保留所有修改，不提交或推送。

**Goal:** 默认提供“新项目”，冲突时顺延为“新项目 2”等；清空或仅空格也采用可用默认名；Return/小键盘 Enter 完成创建并进入工作台。

**Architecture:** 仅修改原生命名弹窗的名称建议及空白回退，保留模型层的有效名称检查和排他创建。默认按钮沿用 Qt 回车行为，不额外连接导致重复提交的快捷键。接受时将实际默认名填回输入框，目录预览和最终子目录一致。

原生 X11 实测补充：带首页样式的按钮框在加入弹窗布局时会重新关联窗口，在此之前设置默认按钮，显示后会落到“取消”。先加入布局再设置“创建”为默认按钮，保留正常键盘焦点行为；增加同样式父窗口下的原生回归及单次 accepted 信号检查。

## Safety and Review Focus

- 仍创建独立命名子文件夹，不把所选父目录直接初始化为项目。
- 同名文件、目录及悬空符号链接都占用默认名；手动输入非法/冲突名称不可提交。
- 取消仍不写文件；任意创建都保留原文件和删除归属校验。
- 测试真实键盘 Return 和 Key_Enter，验证创建后确实进入工作台。
