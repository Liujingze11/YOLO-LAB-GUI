# 筛选布局验证（2026-11-05）

## 结果

- 未打开图片文件夹时仅显示居中导入卡片，可点击打开或拖入文件夹。
- 导入后切换为约 30/70 的两栏工作区，图片数量和打开按钮在列表顶部，文件名与尺寸在预览顶部，翻页/序号/适应窗口集中在底部。两栏标题与主体对齐。
- 空回收站只占一行；移除图片后展开，可手动折叠。全部移除后仍保持工作区，照片可恢复；恢复到零自动收起。
- 滚动条按需显示；三列缩略图及双图等宽预览保留。
- 进度与取消位于底部任务区域，取消或失败后可重试。外部预览显示“外部图片”，不冒充列表序号。

## 测试与自审

- 新增 7 项交互测试，先确认旧代码全部失败，再实现：初始空状态、点击导入、拖入导入、取消重试、失败重试、回收站折叠及全部移除后恢复、外部及清空预览序号。
- 相关测试 91 项通过（35.622s）。最终全量 unittest 198 项通过（40.038s）。
- 回归发现 Qt IconMode 在 ScrollBarAsNeeded 下即使隐藏滚动条也预留其宽度，原列宽导致第三列换行；按相同可用宽度重新计算后，原三列回归测试通过。真实主窗口另用 36 张图验证有滚动条时仍保持三列。
- 初始导入图标改用具有高分辨率资源的原生 SP_DirIcon；调整按钮选择器，避免被工作区通用尺寸样式覆盖。
- 按后续反馈精简导入卡片文案：移除“添加图片开始筛选”标题，保留“打开图片文件夹”按钮，提示缩短为“或拖入文件夹”。更新截图并复跑筛选控件测试，31 项通过（1.515s）。
- 对状态切换、忙碌禁用、失败反馈、空回收站恢复、预览序号及既有操作进行了单代理代码自审；未改保存或副本生成流程。
- 主窗口测试使用临时配置/项目并验证个人 software.yaml 哈希不变；未提交或推送。`git diff --check` 通过。
