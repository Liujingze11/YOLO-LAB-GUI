# 灰白黑配色修正

用户指出上一版彩色玻璃偏离所需的苹果系统/Apple Store 中性色调。本次仅调整外观颜色：

- 去除蓝紫及青色光晕，背景使用 RGB 通道相等的灰白渐层。
- 主文字改为 `#1d1d1f`，说明使用中性灰；卡片、边框、图标与阴影去除蓝灰染色。
- 浅色日志区改为白底黑字，深色模式使用炭灰背景；透明材质和圆角层次保留。
- 蓝色用于选中、焦点、链接及主要操作，停止按钮保留危险色。照片与标注颜色保持原样。
