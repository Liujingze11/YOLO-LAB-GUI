## 行为

- 点击打开卡片，选择之前创建时命名的项目文件夹，直接恢复工作台与训练参数，加入最近项目，重复打开不产生重复记录。
- 选择时只读验证有效项目记录。取消、普通文件夹、仅有 projects 子目录的普通目录、损坏记录及受保护位置不会被初始化为项目。
- 复用原切换流程的未保存内容和后台任务守卫，通过后才登记最近项目，不提前修改所选目录。
- 文件、名称和训练草稿保留；打开不创建嵌套项目，不弹出命名窗口。旧版、复制或移动的目录不因此获得整目录删除权限。
- 新建、打开及最近项目卡片全部保持 300×284，首页刷新及时隐藏旧卡片。
