## 最低打开标准

| 现有内容 | 打开后的行为 |
| --- | --- |
| 至少一张可读取的图片，可在子目录中 | 打开筛选并生成独立工作副本；不要求标注、完整目录或软件生成的项目标记。 |
| 图片旁的 ISAT JSON，或 images/json 对应结构 | 校验图片尺寸、类别和轮廓坐标；工作副本保留标注，可进入原生 ISAT 画布。 |
| data.yaml / data.yml / dataset.yaml / dataset.yml | 校验类别、train 和给出的 val/test 路径及现有 YOLO 标签，支持图片目录与 TXT 清单；自动进入模型开发并填入原始配置路径。缺失标签允许保留为未标注图片。 |
| 有效的原生项目记录 | 沿用原生项目恢复及删除资格判断。 |
| 空目录、只有目录名没有图片、全部损坏图片或损坏的配置/标注 | 提示具体原因，不初始化外部目录。空项目仍可通过必填名称的新建入口创建。 |

YOLO 标签在本次功能中用于验证数据配置，不转换成 ISAT 标签；进入模型开发不启动训练。首次检查内容会扫描图片，尚未针对超大目录、远程盘或 GPU 训练进行性能验证。

## 文件与状态保护

- 外部来源的项目记录、封面、筛选副本、默认输出位置都在应用配置下的独立工作区，原目录不写入 marker、projects 或配置。
- 最近列表、复制路径和打开文件夹始终使用原始来源路径。外部项目不能整目录删除；从列表移除保留原文件和已有工作副本。
- 工作区按来源路径及目录身份隔离。同一路径被替换后不混入旧数据；切换确认期间目标被替换会中止。旧回调不会写入替换后的项目。
- 首次筛选在后台复制图片及有效 ISAT 标注；再次打开恢复已有副本和训练草稿，不重复导入覆盖修改。需读取源目录新增内容时，可在筛选中再次打开文件夹。
- 后台任务及未保存内容守卫通过后才创建工作记录。来源目录消失后不显示卡片，关闭程序不重建原目录。
- 界面显示简短项目名及图片来源，内部工作路径不出现在通用项目说明中；可悬停查看真实来源路径。
