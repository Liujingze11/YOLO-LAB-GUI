## 修正与边界

- 卡片固定为 300×284，宽窗口、少量卡片及反复缩放不再拉伸。刷新时立即隐藏旧卡片，避免延迟销毁前出现重复卡片或旧点击入口。
- 命名框初始为空，必须手动输入有效名称。空白、路径分隔符、保留名称、尾部点和同名目录均无法提交；直接回车或调用 accept 也不能绕过。创建成功自动进入功能工作台，只在所选父目录下新建命名子目录。
- 关闭旧版“直接初始化所选位置”的入口。桌面、主目录、常见用户目录、系统顶层目录和应用配置所在位置被保护。误建记录只从配置移除，不修改目录内容，也不移除其下正常的命名子项目。
- 右键新增“从列表移除”，保留文件。旧版及直接采用的目录不能整目录删除；不根据已有 marker 自动授予删除权限。
- 只有软件排他新建的目录带有创建来源、名称、父路径及目录身份。删除入口验证这些记录，并在确认后再次检查；符号链接、复制 marker 后替换目录、确认期间替换目标均无法删除。成功删除仍使用系统回收站。
- 当前项目的未保存内容、运行中的任务、移除后的配置和退出行为继续保留相应保护。
