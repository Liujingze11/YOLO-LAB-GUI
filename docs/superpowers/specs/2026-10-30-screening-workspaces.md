# 筛选工作空间与拖动操作

用户已确认：操作副本，在导航栏选择工作空间；图片可拖入、定向替换、加入对比、拖回左栏；删除先入回收站，保存成功后才询问是否永久删除副本。

- 导航增加“工作空间”入口；筛选页显示当前路径，可选择工作空间和重新打开已保存项目。记住上次位置；首次打开图片文件夹前要求选择位置。
- 导入时后台复制图片及已有 ISAT JSON 到工作空间独立项目，原始目录从此只读。项目保存 images/、json/、隐藏回收站和项目清单。JSON 不伪造空标注。
- Delete 仅在会话中标记回收，可从回收站多选恢复。保存采用隔离暂存、替换及失败回滚；保存失败不弹清理确认。确认清理仅删除该项目回收站内受管图片/JSON，取消则持久保留，下次打开仍可恢复。重命名与同名冲突检查包含回收站。
- 单图主区域拖入替换，靠右的提示区拖入加入对比；双图时左右分别替换。拖动中显示明确提示。右侧图片可左键拖回缩略图区，仅移出预览；中键平移，滚轮缩放。外部单图仅作预览，不自动成为项目图片。
- 保留三列缩略图、可修改快捷键、ISAT 标注集成。关闭或切换项目时可保存、放弃未保存筛选修改或取消。已有标注项目含未保存标注或 SAM 作业时，阻止改写同项目。
- 仅本地单人使用，在当前分支单代理开发，保留用户配置和其他未提交改动。

验证：核心复制/恢复/重开/清理边界、保存失败与取消；真实 Qt 定向 drop/拖回、保存后的确认时序、导航和原版标注保存；全套回归、启动及界面截图。
