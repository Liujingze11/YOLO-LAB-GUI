# 项目命名统一

用户要求把项目文件中的 ISAT 名称改成符合当前项目的名字。沿用已使用的产品名 YOLO-BACKPROP，仓库保持 YOLO-LAB-GUI；Python 包名为 yolo_backprop，发行包／命令为 yolo-backprop，源码入口为 run-yolo-backprop.sh。

选择完整迁移主包并保留必要兼容入口：仅改界面会继续留下旧主目录；全量替换所有字符串则会破坏 ISAT JSON 格式、第三方插件和来源署名。迁移内部导入、动态加载、模型配置、资源路径、构建脚本、当前文档及关于窗口。根目录类别配置使用 categories.yaml；数据交换的 isat.yaml 和 JSON description 保持兼容。

原作者、许可证、第三方工具名称和历史验证记录保留。旧插件的 ISAT 导入在启动新包后映射到同一模块，避免 Qt 类／枚举重复；兼容旧插件组和旧环境变量。新模型数据目录使用 yolo-backprop，发现旧配置时继续读取旧目录。现有个人 software.yaml 及类别配置按原字节迁移，已有项目数据不批量修改。

产品版本数值仍为 1.5.2，本次不自行制定新发布版本；关于窗口与包元数据采用本项目名称和仓库链接。原上游更新通知不再作为本软件更新提示；更新检查仅查询本项目发布页。当前源码发布和打包说明以本项目为主，原版说明明确列为上游资料。

单代理当前工作区顺序执行，保留全部未提交内容，不提交／推送／发布。旧启动脚本作为转发入口保留以兼容已有桌面快捷方式；规范入口改用新名。
