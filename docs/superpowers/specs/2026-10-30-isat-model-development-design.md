# 以原版 ISAT 为主体增加模型开发板块

日期：2026-10-30。用户明确停止 Electron 重写，确认“开始吧，以 ISAT 为主体”。按此授权直接实施，不重复请求方案确认。单代理顺序开发。

## 范围与界面

原版 ISAT 是主程序，保留它的画布、菜单、工具栏、dock、快捷键、插件、SAM 和文件格式。增加固定的“数据标注 / 模型开发”导航；模型开发包含原 GUI 的训练、推理、导出、结果、工具、设置六页。切换不重建画布或模型页，不丢失当前图像、视口、未保存编辑、表单和日志。模型页激活时屏蔽标注快捷键，返回后恢复原来的 dock 与操作状态。

原程序的 PyQt5 是唯一界面运行时。将用户已有 YOLO-LAB-GUI 的界面和业务模块适配为 PyQt5，并记录源提交和文件摘要；不在同进程引入 PySide6。原 GUI 和 CLI 仓库独立保留，旧 Electron 分支只作参考。算法子进程不导入 Qt。

## 数据衔接

增加“从当前 ISAT 数据准备训练集”入口：先保存当前编辑，读取图片与同名 ISAT JSON；仅导出已有主档的图像，缺标注图片不自动当负样本。保留完整主档备份，YOLO txt 为派生内容。固定类别顺序、复制图片、按种子划分 train/val，生成 data.yaml 和来源清单；临时目录完成后发布到新目录，失败或取消不留下可训练半成品。不覆盖原始图片和标注。自动将生成的 YAML 带入训练页。

## 任务与资源

训练、推理、导出和工具保留原 GUI 的子进程流程、参数、日志和停止能力。停止必须结束子进程组，不能阻塞界面等待五秒或留下数据加载子进程。关闭前提示并停止任务，原 ISAT 未保存编辑检查继续生效。已有 SAM 正占用 GPU 时，GPU 模型开发任务须明确处理冲突，不静默启动第二个重任务。CPU 功能不依赖本机 GPU 驱动。

## 验收

实际运行 PyQt5 界面：六页能构造；完整训练参数可保存/恢复；标注到模型开发再返回时同一画布、对象、视口和原 dock 状态保持；输入模型开发参数不触发标注动作。中文路径、缺失标注、类别映射、可复现划分和中途失败有自动测试。使用已有本地权重做 CPU 短训练与推理；导出格式根据实际可用后端单独记录。旧 ISAT 的 software.yaml 已有修改，保留原字节。测试使用临时设置目录，禁止模型自动下载和版本检查网络访问。
