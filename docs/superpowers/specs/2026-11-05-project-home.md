# 项目首页与自动识别整理

用户确认采用顶部“新建项目／打开项目”、下方最近项目卡片；将名称和位置合并在新建弹窗，并要求打开时增加自动识别整理。

- 延用原生 PyQt5 和现有浅色玻璃风格。首页只将实际项目列为卡片，显示封面、名称、简短路径、类型及最近打开时间；空白项目使用紧凑占位图。
- 新建弹窗同时提供项目名称、保存位置及浏览按钮、最终目录预览；记住成功创建时的位置。保留默认名称、重名和非法路径校验、回车创建、取消无副作用。
- 自动识别已有工作空间、图片、ISAT、YOLO 配置。已有项目恢复；普通图片与有效 ISAT 通过现有后台导入归整为 images/json；同名图片不覆盖。YOLO 数据复制到独立工作目录并生成相对路径配置，保留 train/val/test、类别编号和未标注图片。
- 识别和 YOLO 整理在后台执行，提供进度及取消。展示识别类型和数量，多个候选数据配置或无效标注明确报错，不猜测标签对应关系。
- 原目录不移动、不改名、不删除；再次打开复用已整理副本，不覆盖用户工作。保留切换项目、后台任务和未保存内容守卫。
- 单代理在当前 feature 分支顺序实现，保留已有未提交改动及个人设置，不提交或推送。

## 方案

采用用户确认的“顶部操作＋最近项目”布局。保留原来混排的大操作卡片无法解决操作和内容混淆；新增独立导入向导会增加手动格式选择，因此识别整理由“打开项目”自动完成。
