# 统一快捷键设置

- 一个全局入口，所有工作页面和首页可访问。入口放系统标题栏下方左上角，保留原生窗口装饰。已通过可选问题询问位置偏好，未收到其他选择，采用并告知推荐方案。
- 一个窗口，三个分页：数据筛选、数据标注、模型开发。打开时选中当前功能；首页默认数据筛选。
- 每页单独保存、恢复默认，支持清空绑定。分页保留草稿，关闭有未保存草稿时允许返回继续编辑。
- 同页快捷键不得重复，不同工作页面可复用。标注数字 0–9 保留给类别选择。模型开发只配置现有“运行当前训练 / 推理”操作。
- 保留已有筛选和标注自定义值；新标注/开发设置写用户配置目录，原子替换，失败不改变正在使用的绑定。
- 编辑未激活的页面不能激活其快捷键；切换页面、重建工作区、重开软件均能恢复保存的绑定。
- 筛选工具栏移除局部入口；原筛选右键菜单和标注菜单转到统一窗口。原生 PyQt5，单代理，保留本地已有改动。
