# YOLO-BACKPROP 数据筛选

在原生 PyQt5 主体左侧增加“数据筛选”，与“数据标注 / 模型开发”并列。不替换标注画布，不扩展其他模型功能。单代理在当前 feature 分支实现；保留现有未提交的启动图标和软件配置。

## 本版行为

- 拖入一个本地图片文件夹，或使用“打开文件夹”。递归发现普通图片，异步加载缩略图；忽略非图片，报告损坏图片。
- 缩略图网格、多选、大图预览、前后切换与缩放。删除从本轮筛选移除，重命名修改输出文件名，保留扩展名。原文件不改变（用户尚未要求直接编辑原文件，采用副本默认方案）。
- 同名文件及不同扩展名的同 stem 自动区分，保证一图一 JSON；手工重命名发生冲突时拒绝，不能覆盖。中文、空格路径可用。
- “导入数据标注”选择保存位置，自动创建不覆盖旧文件的新项目 `<源目录>_筛选/`，下含 `images/` 和 `json/`。只复制保留图片。有效的同名 ISAT 标注随图片复制并同步文件名；尚未标注的图片不生成空 JSON。
- 完成后自动切到原 ISAT，设置 image_root 和 label_root，显示第一张图。未保存标注提供保存/放弃/取消；SAM 忙或仍在绘制时不替换数据集。
- 扫描、预览和复制在后台执行；可取消，未完成的项目不发布，失败不覆盖原数据。重新拖入文件夹需确认放弃当前筛选。
- 页面切换保留筛选状态、原画布与模型表单；页面快捷键不触发隐藏的标注动作。

## 选择

原文件直接编辑会立即影响输入数据；副本筛选更适合筛选后导入的工作流。本版采用内存中的筛选记录，在导入时复制，避免提前复制整个文件夹。图片/JSON 分开存储，继续使用原生 ISAT 保存标注。

## 验收

真实临时图片与标注测试原图字节不变、重名拒绝、删除排除、复制回滚、JSON 文件名一致；Qt 拖放、筛选、导入测试；完整既有测试继续通过。截图保存在验证目录。现有 ISAT/software.yaml 的字节必须保持不变。
