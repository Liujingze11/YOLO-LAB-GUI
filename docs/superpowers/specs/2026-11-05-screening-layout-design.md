# 筛选界面空状态与工作布局

用户已批准上一轮提出的四项调整：单一导入空状态、导入后约 30/70 两栏、空回收站折叠、标题及控制栏对齐。

## 设计

- 未打开文件夹：居中导入卡片，提供“打开图片文件夹”按钮与拖入提示。隐藏缩略图、预览、回收站及翻页控件。
- 导入中：进度、状态、取消任务始终可访问，禁止重复导入。失败或取消后可重新打开。
- 导入后：左栏顶部显示图片数量与打开按钮；右栏顶部显示文件名及尺寸。两侧标题等高，主体顶端对齐。预览底部集中显示上一张、序号、下一张、适应窗口及需要时的退出对比。
- 回收站为零时仅显示一行；新增移除图片时展开照片条；支持手动折叠，再恢复到零时自动收起。
- 以是否已有 session 判断工作区状态。全部图片移入回收站仍显示工作区和可恢复照片，不能返回初始导入界面。外部预览不冒充列表序号。
- 滚动条按需显示，维持三列缩略图、可调整分栏及两张等宽预览。

## 实现选择

沿用原生 PyQt5：使用 stacked widget 切换导入页与已有 splitter，保留工作页实例和后台处理流程。仅隐藏空面板会留下零散导入提示和空白容器，因此采用完整空状态。现有保存、对比、拖回列表、原文件保护逻辑继续复用。

不增加新项目类型、数据处理步骤或快捷键。保留已有未提交修改和个人设置；单代理顺序实现。
