# 原生工作台玻璃外观

配色修正：用户明确要求以 iPhone/macOS 通用界面及 Apple Store 的灰、白、黑文字为主。取消上一版蓝紫/青色背景光晕和蓝灰面板；玻璃透明度与层次采用中性灰白。蓝色仅用于焦点、选中、链接及主要操作，危险操作保留红色；深色模式采用炭灰。最新截图与验证见 `2026-11-02-neutral-glass`。

用户要求移除截图中的左侧“工作空间”入口，整体改成苹果风格，多使用透明玻璃组件，其余功能及按钮位置保持。

## 方案

沿用现有 PyQt5 控件、布局和页面切换。采用统一的浅色材质：灰白背景、半透明白色面板、细高光边框、圆角、中性阴影、黑灰文字、蓝色选中态和无衬线中文字体。浅色是本次实现默认值。

现有 UI 是具体实现目标，直接对真实界面换肤；使用网页重写会改变交互与窗口管理，不符合本次要求。只更换几个按钮颜色不足以统一首页、筛选、标注和六个模型页，因此主题同时覆盖这些区域及其原生弹窗。

## 约束

- 左侧保留首页、筛选、标注、模型开发四个入口及其原顺序；移除末尾工作空间入口和对应分隔符。按最新反馈，也移除筛选页右上角“工作空间…”按钮及其旧弹窗，统一通过“返回首页”管理项目。
- 原有布局层次、按钮顺序、工具栏所在边、分割比例、训练参数与任务逻辑不改。
- 玻璃效果通过窗口内柔光底层与透明材质绘制实现，不依赖桌面合成器、平台私有模糊 API 或新依赖；不模糊真实图片、标注、文字。
- 首页卡片保持 300×284；新建默认名称和 Return 行为保留。
- 半透明只用于界面材质，不降低整棵控件树的透明度；禁用、悬停、键盘焦点、选中状态仍可辨。
- 原模型页明暗切换保留并使用同一组材质参数。Linux 字体优先使用已安装的 Noto Sans CJK SC，不下载 Apple 专有字体。
- 保留全部已有脏改动；单代理在当前目录实施，不提交、推送或建立工作树。

## 验证

先用隔离配置抓取首页、筛选、标注及六个模型页基线。修改后在相同窗口尺寸检查布局、文字、滚动和状态，在小窗口复查。通过原项目回归覆盖标注内容、项目创建、默认名称、任务守卫及筛选流程；对导航移除与换肤后键盘提交增加必要的行为检查。所有界面验收只使用临时项目和合成数据，原软件配置 hash 应保持一致。
