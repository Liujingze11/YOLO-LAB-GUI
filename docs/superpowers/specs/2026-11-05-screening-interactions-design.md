# 筛选拖放、多选与双侧翻页

## 范围与约定

用户要求图片区与回收站双向拖动、对比右侧也支持方向键、删除退出对比按钮；最新反馈明确取消勾选框，采用直接框选和组合键多选。沿用原生 PyQt5 和现有筛选副本，不改变导入、保存、原文件保护机制。

## 交互方案

- 采用原生列表 ExtendedSelection：从空白处拖出选区；Ctrl+单击增减选择，Shift+单击连续选择，Ctrl+A 全选当前列表。拖已选缩略图携带整个选区，拖未选缩略图携带该图。曾考虑勾选框／选择模式按钮，用户明确选择直接多选，因此不添加这些控件。
- 图片区 → 回收站调用现有移除逻辑；回收站 → 图片区调用恢复逻辑。回收站标题栏也是落点，折叠时拖入自动展开。落点高亮。取消拖动、无关文件、跨项目及过期拖放不改变筛选记录。
- 对比预览记录当前操作侧：点击哪侧，方向键及底部上下张／序号就控制哪侧，另一侧保持不变。当前侧以细蓝边标识；图片列表的点击仍控制左侧预览。以预览实际路径而非列表当前行确定下一张。
- 开发约定：遍历当前保留图片，跳过另一侧已显示的图片；到边界停止。外部图片没有列表序号，翻页从当前保留列表的首／尾开始。空对比区也能用方向键选图。删除或恢复图片时尽量保持有效的对比内容。
- 删除底部“退出对比”按钮，保留已有 Esc（可自定义）及右键退出；保留预览拖回图片列表的原有操作。

## 实现边界

仅修改筛选控件、其主题和相关测试／说明。内部拖放载荷使用会话标识和记录 ID 校验，复用 session.remove/restore，不直接移动文件。原有单张拖入对比、异步预览过期结果保护保持有效。单代理顺序执行，在当前包含此前 UI 修改的功能分支继续，不提交或推送。

## 追加：自由拖动（用户后续反馈）

- 左右对比图拖到对方位置直接互换，拖回自身保持不变，不退出对比、不触发重复图片提示。落点在松手前提示“互换位置”。
- 互换复用现有像素及各图片的缩放／平移状态，不重新解码、不先清空画面；等待中的预览结果不得覆盖互换后的内容。
- 预览中的项目图片可直接拖入回收站；回收站单张图片拖入任意预览侧时先恢复，再显示到目标侧。外部预览文件不能作为当前项目图片移入回收站。
- 图片列表单张拖入预览仍是替换／加入对比；拖动按下时不提前替换预览，取消保持原画面。原生多选、批量移除／恢复和预览拖回列表继续保留。
- 采用现有原生拖放扩展，替换与互换依目标侧及当前内容判定。保留原生平台拖动循环；不引入动画框架或新按钮。

## 追加：单图左右都可加入对比

- 单图预览左右各 28% 区域均可加入对比：拖左侧，新图在左、原图移到右；拖右侧，新图在右、原图保持左。中间区域继续替换。
- 拖动经过不同区域时实时提示对比方向；回收站单图同样支持两侧恢复并对比。同一张图拖到自身边缘保持单图。
- 原图移位复用缓存及缩放／平移状态，只加载新图；未完成的加载按最终请求路径显示。已有双图仍保持独立替换和互拖换位。
